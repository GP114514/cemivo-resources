# CEMIVO

视频剪辑与 AI 创作工作台。Windows 安装助手约 **215.5 MB**，基础剪辑可以直接使用，AI 组件按需下载。

## 下载安装

**[下载 CEMIVO 0.8.0 安装助手](https://github.com/GP114514/cemivo-resources/releases/download/v0.8.0/CEMIVO-Setup-0.8.0.exe)**

[安装版本与校验文件](https://github.com/GP114514/cemivo-resources/releases/tag/v0.8.0)

1. 下载并双击 `CEMIVO-Setup-0.8.0.exe`。
2. 选择安装位置，跟随安装助手查看安装与校验进度。
3. 如需使用本地 AI，可在安装助手或工作台组件管理器中下载运行环境和模型。

安装助手可选择使用本机代理 `127.0.0.1:7890`，不会改变系统代理。只有本机确实运行该代理时才应启用此选项。

安装包 SHA256：

```text
4a008bf457abf0bed95c7044b67de965415f583d37d087b970a1b335debc05cc
```

## 按需组件

[H3 本地运行环境与音频组件](https://github.com/GP114514/cemivo-resources/releases/tag/v0.8.0-resources)包含 18 个资源分卷，下载总量约 **3.29 GB**。安装助手会自动下载、校验并安装，无需手动拼接或解压。

其他基础模型由组件管理器从各自的官方来源下载。本仓库的资源清单提供分卷及文件的 SHA256 校验记录。
